# 🔧 Telegram-бот для складу автозапчастин

## Структура файлів

```
warehouse_bot/
├── bot.py          — основний код бота
├── database.py     — робота з базою даних (SQLite)
├── requirements.txt
├── start.py        — запуск (вставте токен сюди)
└── warehouse.db    — створюється автоматично при першому запуску
```

---

## ⚙️ Налаштування (крок за кроком)

### 1. Встановіть Python
Завантажте Python 3.11+ з https://python.org  
При встановленні на Windows — поставте галочку **"Add to PATH"**.

### 2. Отримайте токен бота
1. Відкрийте Telegram → знайдіть **@BotFather**
2. Надішліть `/newbot`
3. Введіть назву бота (наприклад: `Мій Склад`)
4. Введіть username (наприклад: `my_sklad_bot`)
5. Скопіюйте токен (виглядає як `123456789:AAF...`)

### 3. Вставте токен
Відкрийте файл `start.py` і замініть рядок:
```
BOT_TOKEN = "PASTE_YOUR_TOKEN_HERE"
```
на:
```
BOT_TOKEN = "ваш_реальний_токен"
```

### 4. Встановіть залежності
Відкрийте термінал у папці `warehouse_bot` і виконайте:
```bash
pip install -r requirements.txt
```

### 5. Запустіть бота
```bash
python start.py
```

Бот працює поки відкрито термінал. Щоб зупинити — натисніть `Ctrl+C`.

## 📱 Використання бота

### Головне меню `/start`
- **🔍 Пошук по номеру** — введіть номер (наприклад `57H945208`)
- **🚗 Пошук по авто** — введіть `Skoda Kodiaq` або просто `Skoda`
- **➕ Додати запчастину** — покроковий діалог
- **📋 Всі запчастини** — список всього складу

### Команди
| Команда | Дія |
|---|---|
| `/start` | Головне меню |
| `/add` | Додати запчастину |
| `/search 57H945208` | Пошук по номеру |
| `/car Skoda Kodiaq` | Пошук по авто |
| `/list` | Всі запчастини |
| `/cancel` | Скасувати поточну дію |

### Картка запчастини
Кожна запчастина відображається з кнопками:
- **➕1 / ➖1** — швидка зміна кількості (натиснув — змінилось)
- **✏️ Кількість** — ввести точну кількість
- **✏️ Редагувати** — змінити будь-яке поле
- **🗑 Видалити** — видалити з підтвердженням

### Автоматичний пошук
Просто надішліть номер запчастини у чат — бот автоматично знайде її.

## 🗄️ База даних

Файл `warehouse.db` (SQLite) — зберігається у папці бота.  
Для перегляду/редагування вручну використовуйте [DB Browser for SQLite](https://sqlitebrowser.org/) (безкоштовно).

### Поля бази даних
| Поле | Опис |
|---|---|
| `part_number` | Номер запчастини *(обов'язкове)* |
| `car_brand` | Марка авто *(обов'язкове)* |
| `car_model` | Модель авто |
| `description` | Опис |
| `price` | Ціна (грн) |
| `quantity` | Кількість на складі |
| `condition` | Стан (Нова / Б/В / До роботи / Битий) |
| `photo_id` | ID фото (зберігається в Telegram) |

---

## 💡 Поради

- Фото зберігаються на серверах Telegram (не на вашому ноутбуці) — не займають місця.
- База даних — єдиний файл `warehouse.db`, його легко скопіювати для резервної копії.
- Щоб бот запускався автоматично при старті Windows — додайте `start.py` у автозавантаження.
